### 6. 아키텍처 테스트 우회 가능성 (SPEC §4.2) - **주의**

지시한 두 사례는 **둘 다 잡힌다**. 정규식이 `import\s+requests\b` / `from\s+time\b` 를 쓰므로 별칭(`as r`)과 `from time import time` 은 접두부가 그대로라 매칭된다. 실측 확인:

```
CAUGHT  import requests as r
CAUGHT  from time import time
CAUGHT      import requests          (함수 안 지연 import, ^\s* 덕분)
```

반면 다음은 전부 빠져나간다(실측):

```
BYPASS  import os, requests                          # 한 줄 다중 import. 패턴이 import 직후만 봄
BYPASS  import sys; import httpx                     # 세미콜론 뒤는 줄 시작이 아님
BYPASS  requests = importlib.import_module("requests")   # 동적 import
BYPASS  mod = __import__("openai")                   # 동적 import
BYPASS  from numpy import random                     # numpy 전역 RNG. SPEC 4.2-2 는 default_rng(seed) 만 허용
BYPASS  numpy.random.seed(1)                         # 전역 시드
BYPASS  seed = hash(payload)                         # SPEC 4.2-2 가 명시적으로 금지한 hash() 시드
BYPASS  import datetime; datetime.datetime.now()     # time 은 막았지만 datetime.now 는 안 막음
BYPASS  from . import requests_shim                  # 엔진 밖 모듈이 requests 를 감싸면 전이적으로 유입
```

구조적 한계 3가지:
1. **문자열 검색이라 AST 를 안 본다.** 위 동적 import·전역 RNG·`hash()` 는 원리상 정규식으로 못 잡는다. `ast.walk` 로 `Import`/`ImportFrom`/`Call` 노드를 순회하면 1~4번과 6~7번이 전부 잡힌다.
2. **전이 의존성을 안 본다.** `fdt/engine/` 이 `fdt/adapters/finapi.py` 를 import 하고 그쪽이 `requests` 를 쓰면 통과한다. import 그래프를 따라가야 한다.
3. **공허한 통과(vacuous pass).** `_engine_py_files()` 는 `ENGINE_DIR` 이 없으면 빈 리스트를 돌려주고(`test_architecture.py:46-48`) 테스트는 그대로 초록불이 된다. 디렉터리 이름이 바뀌거나 경로가 틀어져도 아무도 모른다. `assert len(files) >= N` 가드가 필요하다.

추가로 **놓친 검사**가 하나 있다. PLAN Phase 0 은 "`fdt/engine/**` 는 외부 I/O 없음"(SPEC §4.2)을 요구하는데, `fdt/engine/schemas/export.py:68-83` 이 엔진 디렉터리 안에서 `Path.mkdir` + `Path.write_text` 로 파일을 쓰고 `:31,42,53` 에서 `sys.stderr` 로 출력한다. PLAN §2 목표 구조에도 `export.py` 는 `fdt/engine/schemas/` 에 없다. 아키텍처 테스트가 이걸 못 잡는다.

그리고 `import time` 전면 금지는 SPEC §4.2-2("`time` 기반 시드 금지")보다 넓다. `EngineMeta.elapsed_ms`(SPEC §9.1 필수)를 재려면 `time.perf_counter()` 가 필요하므로, Phase 3 에서 이 금지가 곧바로 충돌한다. 지금 규약을 정해 두는 편이 낫다.

부수 사항: 금지 문자열 `"yaml"` 이 대소문자 무시 전체 검색이라(`:66-69`) 엔진 docstring 에 "프로필 YAML 을 읽지 않는다" 라고 적기만 해도 테스트가 깨진다. 의도된 엄격함일 수 있으나 함정이므로 주석에 명시할 것.
