# ERROR

- 출처: https://project.ssafy.com/docs/ssafy-finance/error
- 크롤링 날짜: 2026-08-24
- 범위: 화면에 표시된 정적 문서 본문만 추출했으며, 실제 API 호출·인증·데이터 변경은 수행하지 않았습니다.
- 요약: 공통 오류 응답 형식과 앱 관리자·사용자·HEADER·업무별 에러코드 목록(3.2~3.14)을 정리합니다. 예시 API KEY와 USER KEY 값은 redacted 처리했습니다.

## 3. 에러코드

API 호출 시 발생할 수 있는 **에러 코드 목록**을 제공합니다.
