# 평가 리포트 (SPEC §12)

## 변경 이력 (L1, S49 적용)

리뷰 `docs/reviews/20260907_W6_W10.md` 항목 2-3(A·D 커버리지 이탈, 추정
표본 오차 ±26%)·SPEC §14 R10·제안 S49 에 따라 Behavior 추정 창을
`[as_of-89, as_of]` 90일 고정에서 "가용 이력 전체, 상한 180일" 로
완화했다(`fdt/engine/behavior.py: estimate_behavior(window_days=None)`
기본값, `build_engine` 이 `None` 을 그대로 전달). 6개월 생성 프로필은
이력이 약 180일이므로 이 변경만으로 창이 90일 -> 180일로 거의 2배
늘어난다(예: A_steady seed=7 외식 봉투 n_obs 89 -> 173건).

측정은 5 시드(1,3,5,7,11) × 4 프로필, `n_paths=1000`, `fdt eval backtest`
로 3가지 안을 비교했다: **(a) 변경 전(90일 고정)**, **(b) 창 180일만**,
**(c) 창 180일 + daily_rate 축소 추정(shrinkage, alpha=14, pooled_rate 로
당김)**. 축소 추정은 표본이 얇은 봉투의 `daily_rate` 를
`(n_e + 14·pooled_rate) / (n_days + 14)` 로 전 봉투 평균 쪽으로 당기는
안이었다.

**채택안: (b) 창 180일만(가용 이력 전체, 상한 180일). daily_rate 축소
추정(alpha=14)은 시도·측정했으나 채택하지 않는다.** 근거:
- (a)->(b): sMAPE 는 A/B/D 전부 개선(D 0.0119->0.0101, B 0.0935->0.0844,
  4/5->5/5 통과로 SPEC §12 기준 자체를 처음 통과), C 만 소폭 악화
  (0.5301->0.5689, 이미 FAIL 이라 판정 변화 없음 - C 는 리뷰가 이미
  "부분 체결(S46)로도 안 고쳐지는 잔액-소비 되먹임 분산" 이라 특정한
  별개 문제). 커버리지는 A(0.767->0.907)·B(0.827->0.853, **처음
  5/5 PASS**)·C(0.867->0.853) 는 개선/유지, D 만 평균은 올랐지만
  (0.740->0.780) 시드 통과가 3/5->2/5 로 줄었다(seed 11 이 0.900 에서
  0.967 로 과다커버리지 쪽으로 넘어감) - **개선(과소)과 새 실패(과다)가
  같은 근본 원인(모수 불확실성)의 다른 얼굴**이라는 판정이다.
- (b)->(c): 축소 추정을 더하면 A/C 는 커버리지가 오히려 나빠지고
  (A 0.907->0.900, C 0.853->0.847), **D_goal_saver seed=1 이 0.233 에서
  0.067 로 더 악화**되며 B 는 처음 통과했던 5/5 가 다시 4/5 로
  퇴행한다. 전 봉투 pooled 평균으로 당기는 것은 "표본이 얇아서" 가 아니라
  "그 시드의 실제 소비 과정 자체가 다른" 경우까지 똑같이 당겨 편향만
  더한다 - 리뷰가 이미 지적한 "n_paths 를 늘려도 해결 안 됨(경로 분산이
  아니라 모수 불확실성)" 과 같은 계열의 실패다.
- **잔여 문제(v0.2 로 이월 제안, SPEC 반영 문장은 아래 참조)**: 커버리지
  완전 해결에는 파라미터 자체의 표본 오차를 경로에 반영하는 부트스트랩이

## 미달 항목 원인 메모

측정 시점: L1(S49, Behavior 추정 창 90일 고정 -> 가용 이력 전체·상한
180일)이 반영된 코드로 측정했다. 위 "변경 이력" 절의 (b)안(창 180일만,
채택)이 아래 표에 그대로 실려 있다. K1(시뮬레이터 S45/S46/S48)도 이미
반영돼 있다(리포트 상단 표는 K1+L1 누적 결과).

**백테스트 sMAPE — B/C FAIL, A/D PASS(A/D 는 S49 로 추가 개선).**
- A(0.0176->0.0145)·D(0.0119->0.0101)·B(0.0935->0.0844, **4/5->5/5 로
  처음 SPEC §12 기준(0.25) 통과**)는 창 확대로 개선됐다 - 표본이
  늘면서 봉투별 λ 추정이 안정된 만큼 시뮬레이션 median 궤적도 원장
  실현치에 더 가까워졌다. C 만 소폭 악화(0.5301->0.5689, 이미 FAIL 이라
  판정 자체는 불변) - 리뷰가 이미 "게이트 방식이 아니라 잔액-소비
  되먹임 루프의 분산" 이라고 특정한 별개 원인(C 프로필 최저 잔액이
  0 근처를 오가며 매 스텝 흑자/적자 판정이 뒤집히는 구조적 문제)이라
  Behavior 창 확대로는 건드릴 수 없다.
- **가설**: C 는 여전히 리뷰가 제안한 대로 기준치(.40) 재조정 또는
  시뮬레이터 쪽(되먹임 루프) 추가 개입이 필요하다(L1/K1 담당 밖).

**백테스트 커버리지 — 전 프로필 FAIL(개별 시드 기준 2~4/5), B 만 5/5 PASS.**
- B 는 이번 판에서 처음 5/5 를 달성했다. A/C 는 시드 통과 수가 그대로지만
  평균 커버리지는 개선(과소커버리지 시드가 줄었다). **D 는 시드 통과가
  3/5 -> 2/5 로 오히려 줄었다** - seed 1 은 여전히 0.233(과소, 변경 전과
  거의 동일)인데 seed 11 이 0.900(PASS)에서 0.967(과다, FAIL)로
  넘어갔다. "변경 이력" 절에서 측정한 대로 daily_rate 축소 추정(alpha=14)
  은 이 문제를 고치지 못했고(seed 1 이 오히려 0.067 로 더 나빠짐) 기각
  했다. 근본 원인은 여전히 리뷰 R10 이 지적한 "모수 자체의 표본 불확실성
  이 경로에 반영되지 않는다" 는 것이고, 정공법(파라미터 부트스트랩)은
  이번 판 범위 밖(v0.2)이다.

**최저점 오차 — 전 프로필 PASS(변경 없음).** 금액 기준으로는 5 시드
전부 기준(30만/50만원) 안이다. C 의 최저점 **일자** 편차(seed 1 -19일,
seed 7 -20일)도 그대로 남아 있다 - Behavior 창 확대는 이 현상(median
궤적이 초반에 바닥을 찍는 패턴)에 영향을 주지 않는다.

**캘리브레이션 — 두 채널 전부 PASS(ECE ≤ 0.15, Brier < 기준율 Brier,
변경 전과 대동소이).** `card_shortfall_prob` ECE 0.0243 안팎, 새
