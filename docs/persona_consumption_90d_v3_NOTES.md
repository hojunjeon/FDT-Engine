## 스키마 의미 (v3에서 확정)

- `is_fixed` = 매 주기 금액이 같은가. `is_recurring` = 주기적으로 반복되는가.
  월세·통신비는 TRUE/TRUE, 전기·가스·관리비는 FALSE/TRUE, 급여·연금은 TRUE/TRUE.
- `spend_pattern`: ROUTINE / PLANNED / FIXED / IMPULSE. 지출과 저축 이체에만 쓰고 INCOME 행은 `N/A`.
- `classify_source` / `confirm_status`
  - 전국 체인·온라인 플랫폼: MERCHANT_MAP / AUTO
  - 동네 가맹점 첫 거래: MODEL / CONFIRMED, 두 번째부터 RULE / AUTO (사용자 확정 후 규칙화)
  - 자동이체·공과금·급여: RULE / AUTO
  - 개인 간 송금: USER / CONFIRMED
  - 각 페르소나 마지막 주에 신규 가맹점 1건 MODEL / PENDING
- 첫 거래에서는 반복성을 알 수 없으므로 동네 가맹점의 첫 회원권·수강료는 `is_recurring FALSE`, 두 번째부터 TRUE.
- `merchant_area`: 결제가 일어난 지역. 교통은 승차 지역, 온라인은 "온라인", 해외결제는 "해외".
- `merchant_id`: 페르소나 접두어 `M2-`, `M3-`, `M4-`, `M5-`. 페르소나 안에서만 고유.
- 계좌·카드: `ACC-DEMO-00X`, `CARD-DEMO-00X`. 저축·투자 이체 목적지는 `ACC-DEMO-00X-S`, `-IRP`, `-CMA`.
- 시각은 항상 `HH:MM` 두 자리.

- 계좌 자동이체는 휴일이면 다음 영업일로 이월. 급여·연금은 휴일이면 전 영업일 지급. 카드 자동결제(구독)는 휴일 무관.

- KTX는 사전 예매 행만 있고 탑승 당일에는 앞뒤 시내 교통만 기록.
- 프리랜서 대금은 3.3% 원천징수 후 금액. 해외 구독은 달러 정액을 월별 환율로 원화 환산해 금액이 조금씩 다름.
